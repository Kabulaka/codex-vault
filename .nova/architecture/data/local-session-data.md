# Codex Vault 本地会话数据契约

> 数据契约版本：1
> Contract-Key：DATA-01
> 所有者：本地会话整理模块

## 1. 所有权

| 数据对象 | 权威写入方 | 允许读取方 | 禁止行为 |
|----------|------------|------------|----------|
| Codex 会话元数据、运行状态、父子关系和归档状态 | Codex app-server | Codex 接入模块只读，其他模块只能读取类型化快照 | Codex Vault 直接修改 Codex 数据库、会话文件或未知字段 |
| 筛选与语言偏好 | 本地记录模块 | 会话整理与终端交互模块 | 保存消息正文、凭据、Codex 配置或未声明字段 |
| 操作批次与逐会话结果 | 本地记录模块 | 会话整理与终端交互模块 | 把计划状态当作 Codex 实际状态，或用标题和正文形成历史副本 |

## 2. 数据约束

| 字段或关系 | 类型或范围 | 不变量 | 兼容规则 |
|------------|------------|--------|----------|
| 会话 ID | 非空不透明字符串 | 只用于关联、展示和请求，不假设 UUID 或路径格式 | 格式变化不影响领域层；空值使对象不可操作 |
| 会话树 | 一个根节点及零到多个后代 | 写计划必须包含查询时可证明的全部后代；关系不完整时不可写 | 新关系字段由 Codex 适配器吸收，领域闭包语义不变 |
| 最后活动时间 | UTC 时间点 | 会话树时间取全部节点最大值；展示时才转换为本地时区 | 无法解析或缺失时不进入按时间写计划 |
| 运行保护状态 | `notLoaded`、`idle`、`systemError`、`active` 及未知值 | `active`、排队、等待交互和未知值均不可写；只有明确安全状态可继续 | 新枚举默认受保护，显式适配后才能放行 |
| 固定状态 | 布尔值或未知 | 固定或未知节点所在整棵树不可写 | 缺失按固定处理，不用默认 false 掩盖 |
| 筛选偏好 | 语言、滚动时长或截止时间、项目和状态条件 | 首次时间为三十天；后续恢复最后一次有效选择 | 新字段必须有安全默认并允许旧记录继续读取 |
| 操作批次 | 唯一批次 ID、动作、创建时间、计划数量、状态 | 调用任何 Codex 写操作前必须存在待执行批次 | 模式升级必须事务化；未知状态不得自动执行 |
| 操作项目 | 批次 ID、会话 ID、动作、结果和完成时间 | 每个计划节点至多一个当前结果，不保存标题或正文 | 新结果值向后兼容展示；未知值不得视为成功 |
| 保留期 | 九十个连续自然日 | 只清理过期的 Codex Vault 记录，不影响 Codex 会话 | 用户清空等同于显式缩短自有记录，不触发会话操作 |

## 3. 一致性与并发

| 场景 | 原子边界 | 并发结果 | 幂等规则 |
|------|----------|----------|----------|
| 更新偏好 | 单次本地事务 | 后写入的完整有效偏好生效 | 重复写入同一偏好结果不变 |
| 建立操作计划 | 批次与全部操作项目在一个事务中写入 | 无法完整记录时整批失败且不调用 Codex 写操作 | 同一不可变计划重复提交返回既有批次 |
| 记录逐项结果 | 单个操作项目及批次聚合状态事务化 | 后续实际状态核对可替换未决或中断结果，不能覆盖已观察成功为推断失败 | 同一会话、动作和已观察结果重复记录不新增项目 |
| 清理保留期 | 过期批次及其项目在一个事务中删除 | 与当前批次冲突时跳过当前批次 | 重复清理得到相同保留集合 |

## 4. 失败与恢复

| 失败点 | 对外结果 | 恢复或补偿 | 责任方 |
|--------|----------|------------|--------|
| SQLite 不可创建、不可写或事务失败 | 所有状态变更保持禁用并说明本地记录不可用 | 修复权限后重试；不触碰 Codex 状态 | 本地记录模块 |
| 模式迁移失败或文件损坏 | 保留原文件并进入只读状态 | 隔离损坏副本后显式重建空库；不伪造历史记录 | 本地记录模块 |
| 写操作后结果记录失败 | 显示结果待核对，不宣称成功或失败 | 重新列出 Codex 实际状态并更新待执行批次 | 会话整理模块、本地记录模块 |
| 进程在批次执行中退出 | 下次启动显示中断批次 | 重扫全部计划节点，以可观察实际状态完成核对 | 会话整理模块 |
| 保留期清理失败 | 继续保留旧记录并提示维护失败 | 后续启动重试，不影响会话整理 | 本地记录模块 |
