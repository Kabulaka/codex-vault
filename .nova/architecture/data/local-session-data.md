# Codex Vault 本地会话数据契约

> 数据契约版本：4
> Contract-Key：DATA-01
> 所有者：本地会话整理模块

## 1. 所有权

| 数据对象 | 权威写入方 | 允许读取方 | 禁止行为 |
|----------|------------|------------|----------|
| Codex 任务目录、父子关系、归档状态和正文路径 | Codex 自身状态库；脏数据维护仅拥有已证明失效数据的清理权 | Codex 接入模块读取所需任务元数据与关系，其他模块只能读取类型化快照 | 绕过官方 CLI 修改有效任务，或在缺少完整目录、路径和关系证据时执行清理 |
| Codex 运行状态 | Codex app-server | Codex 接入模块以 metadata-only 请求补齐目录任务的当前运行态 | 用 app-server 列表缩小状态库目录，或请求消息 turns |
| Codex 正文、辅助索引和历史投影 | Codex CLI；脏数据维护可隔离未引用正文并移除已删除目录项的精确索引行 | Codex 接入模块只核验任务 ID、准确路径和存在性，不解析消息正文 | 修改有效正文、模糊匹配索引、删除 `-wal`/`-shm`、读取 `auth.json`，或清理未形成候选的历史投影 |
| 脏数据备份 | Codex 接入模块 | 终端交互只显示批次备份路径，不读取备份内容 | 把备份放回会话扫描根、解析或展示正文、无期限生成重复副本，或在备份未完成时删除源数据 |
| 筛选与语言偏好 | 本地记录模块 | 会话整理与终端交互模块 | 保存消息正文、凭据、Codex 配置或未声明字段 |
| 操作批次与逐会话结果 | 本地记录模块 | 会话整理与终端交互模块 | 把计划状态当作 Codex 实际状态，或用标题和正文形成历史副本 |

## 2. 数据约束

| 字段或关系 | 类型或范围 | 不变量 | 兼容规则 |
|------------|------------|--------|----------|
| 会话 ID | 非空不透明字符串 | 只用于关联、展示和请求，不假设 UUID 或路径格式 | 格式变化不影响领域层；空值使对象不可操作 |
| 目录元数据 | 标题、cwd、项目、provider、model、归档位、置顶位与更新时间 | 历史任务按记录自身 provider/model 筛选，不以当前 `config.toml` provider 推断包含范围 | 缺列、非法类型或重复 ID 使目录能力失败封闭 |
| 正文路径 | 状态库记录的绝对 JSONL 路径 | 未归档路径必须位于 `$CODEX_HOME/sessions/**`，归档路径必须位于 `$CODEX_HOME/archived_sessions/`；只核验常规文件，不跟随符号链接 | `sessions` 递归扫描，`archived_sessions` 平铺扫描；未被目录引用的常规文件形成显式清理候选，不自动执行 |
| 脏数据候选 | 未引用正文、子任务不存在的父子关系、正文常规文件不存在的目录行 | 候选包含稳定键、类别、展示元数据、空间和执行前重算的指纹；任何权限错误、路径越界、符号链接或证据漂移均不具备资格 | 新类别必须先定义完整证据、备份、执行和重扫语义；普通诊断不能自动升级为可清理项 |
| 脏数据备份 | `$CODEX_HOME/codex-vault-backups/<batch-id>/` 下的不透明文件副本与 SQLite 在线备份 | 每个批次先备份后删除；备份目录权限仅当前用户可访问；SQLite 使用在线备份 API，不复制或删除 WAL/SHM | 同批次重复执行复用已经校验的备份；不同大小的既有备份使操作失败关闭 |
| 会话树 | 一个根节点及零到多个后代 | 写计划必须包含查询时可证明的全部后代；关系不完整时不可写 | 新关系字段由 Codex 适配器吸收，领域闭包语义不变 |
| 最后活动时间 | UTC 时间点 | 会话树时间取全部节点最大值；展示时才转换为本地时区 | 无法解析或缺失时不进入按时间写计划 |
| 运行保护状态 | `notLoaded`、`idle`、`systemError`、`active` 及未知值 | `active`、排队、等待交互和未知值均不可写；只有明确安全状态可继续 | 新枚举默认受保护，显式适配后才能放行 |
| 固定状态 | 布尔值或未知 | 状态库目录必须为每个任务提供明确值；固定或未知节点所在整棵树不可写 | 缺失、非法布尔值或重复冲突保持未知，不用默认 false 掩盖 |
| 删除完成 | 目录行、准确正文路径、辅助索引、附件/动态工具/父子关系和可用历史投影均无目标 ID | 任何残留或不可核验都不得记录成功 | 客户端跨主机目录缓存只提示重启刷新，不由服务端改写 |
| 筛选偏好 | 语言、全部/滚动时长/绝对截止时间、项目和状态条件 | 首次时间为三十天；后续恢复最后一次有效选择 | 新字段必须有安全默认并允许旧记录继续读取；图形预设与高级文本查询按 AND 组合 |
| 操作批次 | 唯一批次 ID、动作、创建时间、计划数量、状态 | 调用任何 Codex 写操作前必须存在待执行批次 | 模式升级必须事务化；未知状态不得自动执行 |
| 操作项目 | 批次 ID、会话 ID或脏数据候选键、动作、结果和完成时间 | 每个计划项目至多一个当前结果，不保存标题或正文 | 新结果值向后兼容展示；未知值不得视为成功 |
| 保留期 | 九十个连续自然日 | 只清理过期的 Codex Vault 记录，不影响 Codex 会话 | 用户清空等同于显式缩短自有记录，不触发会话操作 |

## 3. 一致性与并发

| 场景 | 原子边界 | 并发结果 | 幂等规则 |
|------|----------|----------|----------|
| 更新偏好 | 单次本地事务 | 后写入的完整有效偏好生效 | 重复写入同一偏好结果不变 |
| 建立操作计划 | 批次与全部操作项目在一个事务中写入 | 无法完整记录时整批失败且不调用 Codex 写操作 | 同一不可变计划重复提交返回既有批次 |
| 记录逐项结果 | 单个操作项目及批次聚合状态事务化 | 后续实际状态核对可替换未决或中断结果，不能覆盖已观察成功为推断失败 | 同一会话、动作和已观察结果重复记录不新增项目 |
| 清理孤立正文 | 原文件备份同步完成后再删除源文件 | 文件或指纹变化使该项失败，其他已选择项目可继续并逐项报告 | 备份存在且内容大小一致时允许重试；重扫不再出现候选才记录成功 |
| 清理陈旧关系或缺失正文目录行 | 状态库在线备份后，每个候选在 SQLite 事务内按完整键删除；精确索引行使用同目录临时文件原子替换 | 受影响行数不是预期值即回滚并标记预览过期；索引与事务任一失败保留备份和实际结果 | 执行前重读候选指纹；目标不存在由最终重扫判定，不把未观察状态推断为成功 |
| 清理保留期 | 过期批次及其项目在一个事务中删除 | 与当前批次冲突时跳过当前批次 | 重复清理得到相同保留集合 |

## 4. 失败与恢复

| 失败点 | 对外结果 | 恢复或补偿 | 责任方 |
|--------|----------|------------|--------|
| SQLite 不可创建、不可写或事务失败 | 所有状态变更保持禁用并说明本地记录不可用 | 修复权限后重试；不触碰 Codex 状态 | 本地记录模块 |
| 模式迁移失败或文件损坏 | 保留原文件并进入只读状态 | 隔离损坏副本后显式重建空库；不伪造历史记录 | 本地记录模块 |
| 写操作后结果记录失败 | 显示结果待核对，不宣称成功或失败 | 重新列出 Codex 实际状态并更新待执行批次 | 会话整理模块、本地记录模块 |
| 进程在批次执行中退出 | 下次启动显示中断批次 | 重扫全部计划节点，以可观察实际状态完成核对 | 会话整理模块 |
| 保留期清理失败 | 继续保留旧记录并提示维护失败 | 后续启动重试，不影响会话整理 | 本地记录模块 |
| Codex 状态库不存在、无法只读打开或模式不兼容 | 扫描仅作为兼容展示，写操作保持禁用 | 提示重新扫描或升级兼容适配；绝不创建、迁移或修复 Codex 状态库 | Codex 接入模块 |
| Codex 状态库缺列、值非法、关系冲突或正文路径越界 | 不把缺失项推断为安全值，受影响范围不可选择 | 保留可验证元数据供诊断，修复环境后重新扫描 | Codex 接入模块 |
| 脏数据备份创建、同步或校验失败 | 对应候选不修改，显示失败 | 修复备份目录权限或空间后重新预览；不得跳过备份继续 | Codex 接入模块 |
| 脏数据执行中断或最终重扫失败 | 已执行项目保持中断或待核验，备份路径保留在结果中 | 下次启动重扫；候选仍存在时可复用不可变计划和备份重试，不直接删除 WAL/SHM | Codex 接入模块、会话整理模块、本地记录模块 |
| 正常会话删除后任一正文、索引、关系或历史投影仍含目标 ID | 逐项结果保持失败或待核验，不宣称成功 | 先交给官方 Codex CLI 重试；只有重新扫描后形成独立脏数据候选，才可进入受控清理 | Codex 接入模块、会话整理模块 |
