# 本地会话整理

> 需求块规范版本：1
> Requirement-Key：REQ-01a08e5a-fe60-749a-8bc9-5b1b292e02d6
> 需求版本：v1
> 所属模块：本地会话整理

## 1. 目标

| 业务问题 | 成功结果 |
|----------|----------|
| 本地 Codex 会话长期积累后难以定位已完成工作，物理删除又缺少足够的筛选、预览和恢复保护 | 用户能只依据会话元数据找出目标会话，主动选择后整树归档或恢复，并通过严格门禁永久删除已归档会话 |

## 2. 参与者与业务流程

| 步骤 | 参与者 | 触发与输入 | 业务结果 |
|------|--------|------------|----------|
| 1. 进入会话列表 | 本地 Codex 用户 | 在 Linux 或 macOS 终端启动工具 | 工具以用户选择的语言展示本机全部项目的会话元数据 |
| 2. 设置筛选条件 | 本地 Codex 用户 | 选择最后活动时间、项目、工作目录、标题、会话 ID 或归档状态条件 | 工具按完整会话树计算并展示匹配结果及排除原因 |
| 3. 选择操作对象 | 本地 Codex 用户 | 从默认未勾选的候选中主动选择一个或多个会话树 | 工具形成明确的操作集合，不自动扩大选择范围 |
| 4. 预览影响 | 本地 Codex 用户 | 选择归档、恢复或永久删除 | 工具只读展示会话树、影响数量、保护状态和拟执行动作 |
| 5. 执行归档或恢复 | 本地 Codex 用户 | 确认通过预检的会话树 | 工具按整棵树改变归档状态，并展示每棵树的实际结果 |
| 6. 执行永久删除 | 本地 Codex 用户 | 选择全部节点均已归档的会话树，并输入与预览一致的删除数量 | 工具永久删除通过门禁的会话树，数量不一致时保持全部对象原状 |
| 7. 查看与恢复结果 | 本地 Codex 用户 | 本次结果或最近九十天的操作记录 | 工具展示成功、跳过和失败，重新扫描当前状态，并允许重试归档或恢复 |

## 3. 业务规则

| 规则 | 唯一定义 |
|------|----------|
| R-01 | MVP 仅管理当前用户本机的 Codex 会话，启动后默认覆盖全部项目；不连接或管理远程主机。 |
| R-02 | 会话发现、搜索和筛选只使用会话 ID、标题、项目、工作目录、最后活动时间、归档状态、固定状态、运行状态和父子关系，不读取、索引或搜索消息正文。 |
| R-03 | 时间条件按完整会话树中最后一次活动计算；`1d` 表示从当前时刻回溯连续二十四小时，只有整棵树的最后活动时间达到或早于截止点时才匹配。 |
| R-04 | 首次启动的时间阈值为三十天；此后恢复用户上次使用的阈值，并提供一天、七天、三十天及自定义截止时间。 |
| R-05 | 所有筛选结果默认均不勾选；只有用户主动选择的完整会话树才能进入操作预览。 |
| R-06 | 固定会话必须先取消固定；正在运行、排队或等待用户交互的会话属于硬保护对象，不能归档、恢复或永久删除，也不能由筛选开关绕过。 |
| R-07 | 根会话与其全部派生会话构成不可拆分的操作对象；任一节点受保护时阻止整棵树的状态变更。 |
| R-08 | 每次状态变更前必须重新校验候选，并只读展示标题、会话 ID、项目、最后活动时间、父子关系、匹配原因、排除原因、影响数量和拟执行动作；确认前不得改变任何会话状态。 |
| R-09 | 归档和恢复均以完整会话树为单位；成功归档的记录保持可恢复，归档数量不能被表述为已经释放的磁盘空间。 |
| R-10 | 永久删除只允许处理整棵树均已归档且无受保护节点的对象；存在任何未归档派生会话时必须拒绝删除。 |
| R-11 | 永久删除预览必须列出实际受影响的完整会话树；用户输入的预计删除会话数量必须与预览一致，否则不得执行任何删除。 |
| R-12 | 批量操作按会话树记录实际成功、跳过和失败；出现部分失败时重新扫描当前状态，保留已发生的真实结果并允许用户重试，不得把部分完成报告为整体成功。 |
| R-13 | 操作记录只保存时间、动作、会话 ID 和结果，不保存消息正文；记录默认保留九十天，用户可以手动清空。 |
| R-14 | 工具不能可靠识别当前 Codex 会话能力或无法安全执行目标动作时，必须保持只读并明确告知原因，不得尝试不受支持的状态修改。 |
| R-15 | MVP 通过终端交互界面提供中文和英文，依据用户环境选择初始语言并允许切换；仅承诺 Linux 与 macOS。 |

## 4. 边界与异常

| 场景 | 业务结果或恢复 |
|------|----------------|
| 无法发现本地 Codex 会话或数据不可访问 | 不展示虚构结果，不改变状态，并说明当前用户可执行的检查方向。 |
| 扫描完成后会话进入运行、排队或等待交互状态 | 执行前重新校验并拒绝包含该会话的整棵树，其他树按实际结果继续处理。 |
| 会话在选择后被固定 | 执行前重新校验并拒绝包含该会话的整棵树，要求用户先取消固定。 |
| 父会话已归档但存在未归档派生会话 | 永久删除被拒绝，用户需先完成整棵树的归档。 |
| 用户输入的删除数量与预览不一致 | 取消本次删除，所有候选保持原状。 |
| 批量归档、恢复或删除仅部分成功 | 展示每棵会话树的实际结果，重新扫描，并允许对仍符合条件的对象重试。 |
| 操作记录无法保存 | 明确报告记录失败并以重新扫描后的会话状态为准，不把记录失败掩盖为完整成功。 |
| 当前 Codex 能力与工具不兼容 | 保持只读，展示不兼容原因，不直接改变未知数据。 |

## 5. 独立交付边界

| 交付结果 | 共享业务输入输出 | 架构前置 | 硬依赖 | 明确不做 |
|----------|------------------|----------|--------|----------|
| 一名工程师可独立交付本机会话发现、元数据筛选、整树归档与恢复、受控永久删除、双语终端交互、偏好和操作结果追踪的完整闭环 | 输入为当前用户可见的本机会话元数据与状态，输出为用户确认后的归档状态、恢复状态、永久删除结果和可核对操作记录 | 需确认会话元数据来源、状态变更边界、父子关系识别、兼容性门禁与跨平台行为 | 无 | 远程主机、Windows、消息正文搜索、无人值守批处理，以及日志、缓存、插件、配置、认证和命令历史清理 |

## 6. 验收

| 覆盖规则 | 场景 | 预期结果 |
|----------|------|----------|
| R-01 | 用户从任意项目目录启动工具 | 默认能查看本机全部项目的会话，且不会尝试连接远程主机。 |
| R-02 | 用户以标题、会话 ID、项目或工作目录筛选 | 返回匹配的会话元数据，且整个过程不读取或索引消息正文。 |
| R-03 | 某会话树最新活动距当前时刻恰好二十四小时，另一棵树仍有不足二十四小时的派生会话 | 一天条件包含前者并排除后者。 |
| R-04 | 用户首次启动后把三十天改为一天并退出，再次启动 | 首次值为三十天，第二次恢复为一天，同时仍能选择七天、三十天或自定义截止时间。 |
| R-05 | 筛选命中多棵会话树 | 初始没有任何候选被勾选，未主动选择时不能进入执行。 |
| R-06 | 候选中分别存在固定、运行、排队和等待交互的会话 | 这些会话所在的整棵树均显示保护原因且不能被执行。 |
| R-07 | 用户选择包含多个派生会话的根会话 | 预览把完整会话树视为一个操作对象；任一节点受保护时整组被拒绝。 |
| R-08 | 用户进入任一操作的预览页后取消 | 能看到完整影响和排除依据，取消后所有会话状态保持不变。 |
| R-09 | 用户归档一棵完整会话树后从已归档视图恢复 | 整棵树先从活动列表移出，随后完整恢复；界面不把归档数量显示为已释放空间。 |
| R-10 | 已归档父会话仍有一个未归档派生会话 | 永久删除入口拒绝该会话树，不删除任何节点。 |
| R-11 | 预览显示将删除五个会话，用户分别输入四和五 | 输入四时无删除发生；重新确认并输入五时才允许执行。 |
| R-12 | 批量操作中部分会话在执行时失败 | 结果逐棵树显示成功、跳过和失败，重扫后的状态与实际结果一致，失败对象可再次选择。 |
| R-13 | 用户查看九十天内记录并清空记录 | 只看到时间、动作、会话 ID 和结果；清空后记录消失且会话状态不受影响。 |
| R-14 | 当前环境缺少工具可可靠使用的会话能力 | 工具说明不兼容并保持只读，没有会话状态被修改。 |
| R-15 | 用户分别在 Linux 与 macOS 上以中文和英文环境启动并切换语言 | 两个平台均能使用完整流程，初始语言符合环境且切换后主要界面文案一致变化。 |
