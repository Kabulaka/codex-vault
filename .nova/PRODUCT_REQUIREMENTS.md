# Codex Vault — 产品需求

> 需求规范版本：1
> 产品版本：v1
> 文档定位：总体业务流程、业务模块与需求块索引的长期契约。

## 1. 产品定位

| 对象 | 核心问题 | 成功结果 |
|------|----------|----------|
| 使用本地 Codex 的个人用户 | 长期积累的会话难以按时间和项目整理，直接删除又容易造成不可恢复的数据损失 | 用户能先筛选和预览，再安全归档、恢复或受控删除会话，并能核对实际执行结果 |

## 2. 端到端业务流程

| 步骤 | 参与者 | 业务输入 | 业务结果 |
|------|--------|----------|----------|
| 1. 启动并扫描 | 本地 Codex 用户 | 当前用户在 Linux 或 macOS 终端启动工具 | 工具展示本机全部项目的可识别会话及其状态 |
| 2. 筛选候选 | 本地 Codex 用户 | 时间、项目、工作目录、标题、会话 ID 和归档状态条件 | 工具列出匹配条件且未受保护的会话树 |
| 3. 选择并预览 | 本地 Codex 用户 | 用户主动勾选的会话树 | 工具在不改变状态的前提下展示拟执行动作、影响范围和排除原因 |
| 4. 归档或恢复 | 本地 Codex 用户 | 已通过预检的会话树及用户确认 | 会话树整体进入归档状态或恢复为未归档状态 |
| 5. 永久删除 | 本地 Codex 用户 | 全部节点均已归档的会话树及匹配的数量确认 | 符合门禁的会话树被永久删除，不符合条件的对象保持原状 |
| 6. 核对结果 | 本地 Codex 用户 | 本次操作结果和历史操作记录 | 用户看到成功、跳过、失败及当前真实状态，并可重试可恢复操作 |

## 3. 业务模块

| 业务模块 | 职责 | 边界 |
|----------|------|------|
| 本地会话整理 | 发现和筛选本机会话，完成预览、归档、恢复、受控删除与结果追踪 | 不读取消息正文，不管理远程主机，不清理日志、缓存、插件、配置、认证或命令历史 |

## 5. 范围边界

| 边界 | 内容 |
|------|------|
| 本期范围 | 面向通用 Codex 用户的 Linux 与 macOS 双语终端界面；管理当前用户本机全部项目的会话；支持元数据筛选、预览、整树归档与恢复、受控永久删除、偏好记忆和操作结果追踪 |
| 明确不做 | 远程主机、Windows、无人值守批处理、消息正文搜索、日志与缓存清理、插件清理、配置与认证修改、命令历史裁剪 |
| 后续候选 | Windows 支持、可脚本化操作、远程会话管理，以及与会话生命周期分离的磁盘空间清理 |
